# Swarm

把任务拆成互不冲突的范围并行处理，最后由主 Agent 汇总。

## 使用条件

只有用户明确要求多个 Agent、并行调查、并行验证或点名 `$swarm` 时启动。

## 工作流

1. 定义完成条件和最终报告格式。
2. 选择并行形态：不同范围的切片、相同任务的竞赛，或二者混合。
3. 每个任务说明目标、范围、输入、允许写入的位置、验证方式和返回格式。
4. 有写操作时，为每个 Agent 分配独立文件、目录或 worktree。不要让多个 Agent 修改同一状态。
5. 同时启动 Agent，默认继承当前模型。
6. 等待所有结果。结果缺少证据时仅重试一次，仍缺失则标记为未覆盖。
7. 主 Agent 检查实际文件、diff 或运行结果，不能只信任子 Agent 的自述。
8. 汇总重复发现，保留分歧和覆盖缺口，不粘贴大段原始输出。

## 输出

返回一份报告，包含每个切片的状态、已证实问题、未覆盖范围、失败 Agent 和最终结论。
