### Orchestrate

用于用户明确要求多 Agent 编排、长期项目协调或大规模并行迁移的场景。普通复杂任务使用 `figure-it-out` 或具体 playbook。

1. 定义可计数的完成条件、范围、禁止修改区域、验证标准和用户授权边界。
2. 将项目拆成互相独立的工作单元。一个工作单元只能有一个写入者。
3. 先完成一个端到端试点，验证任务说明、实现路径和验收方式。
4. 用户已明确授权多 Agent 时，按当前并发限制启动一轮工作。不要创建超过主 Agent 能及时检查的任务。
5. 每个任务说明目标、写入范围、输入、验收命令、停止条件和报告格式。
6. 使用 Codex 子 Agent 等待能力收集完成状态。只读取新增结果，不反复拉取完整记录。
7. 主 Agent 检查实际分支、diff、命令结果和产物。子 Agent 自述不能作为通过证明。
8. 每轮结束后更新工作单元状态、验证状态、依赖和未解决决策，再决定下一轮。
9. 外部消息、PR 合并、部署、删除和权限变更必须由用户请求明确授权。
10. 完成后按真实产物核对完成条件，并留下可恢复的状态摘要。

输出当前完成度、每个工作单元的状态、验证证据、失败或放弃项、需要用户决定的事项和恢复位置。
