### Autonomous run

用于用户明确要求持续推进一个任务直到满足完成条件的场景。持续执行不会扩大任务范围或权限。

1. 把目标转换成可以实际检查的完成条件。
2. 记录允许执行的操作、禁止操作、外部写入权限和必须暂停的条件。
3. 将工作拆成可验证的小单元，每个单元完成后运行真实检查。
4. 能在当前任务内继续时直接推进。等待外部状态时使用 heartbeat automation，不使用阻塞 sleep。
5. 对相同工具错误或失败路径限制重试次数。连续失败后记录现状、证据和恢复命令。
6. 新发现的工作只有在原任务范围内且阻塞完成条件时处理。其他内容记录为后续建议。
7. 外部消息、合并、部署、删除、权限或凭证操作仍按原授权边界处理。
8. 完成后重新运行结束检查，并读取真实产物确认结果。

输出完成条件、实际结果、验证证据、范围内附带修复、未处理建议和恢复信息。
